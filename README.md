# TabPad
iOS/iPadOS application for text editing

TabPad Support

TabPad is a simple, tabbed text editor for iPhone and iPad. Keep several files open, jump between them with a tap, and save them in formats that open almost anywhere: Word, Pages, Google Docs, TextEdit, even Notepad.

❓ FAQ

Files & saving

Where are my files saved?
New files save automatically to TabPad's own folder. You'll find it in the Files app under On My iPhone › TabPad (or On My iPad › TabPad).

How do I save a file to iCloud Drive, Dropbox, or somewhere else?
Open the file's menu and choose Move to…, then pick any location the Files app can see.

Do I need to press Save?
No. TabPad saves as you type.

Why is my file named after its first line?
New files take their name from the first line of text until you rename them. You can rename a file any time from its menu.

Can I open files from other apps in TabPad?
Yes. Use Share or Open in… from Files, Mail, and other apps, and choose TabPad. It opens Rich Text (.rtf), plain text (.txt), and Markdown files.

Formats

What's the difference between RTF and TXT?

	•	RTF (Rich Text) is the default. It keeps your formatting (fonts, bold, highlights and so on) and opens in Word, WordPad, Pages, TextEdit, LibreOffice and Google Docs.
	•	TXT (Plain Text) is text only, with no formatting. Use it when you need a file for a basic editor like Notepad.

You can choose the format per file, convert an existing file, or save a TXT copy. There's a short explainer in Settings too.

My formatting disappeared. What happened?
The file is probably saved as TXT, which can't store formatting. Convert it to RTF from the file's menu. Bullet points are an exception: they're kept as plain characters, so they survive in TXT.

My file looks different in Word on Windows.
Windows doesn't have Apple's system font, so Word substitutes a similar one (usually Arial). Choose a common font such as Arial or Times New Roman if the exact look matters.

Layout

Can I show open files in a list instead of tabs?
Yes. In Settings, switch between Tabs and Sidebar. On iPad the sidebar sits beside your text. On iPhone, swipe in from the left edge of the screen to open it.

How do I reorder tabs?
Touch and hold a tab, then drag it to a new spot. If you have more tabs than fit, swipe the tab strip sideways.

Reminders

What are reminders in TabPad?
You can attach a reminder to a file for a date and time, or for when you arrive at or leave a place. Tap the notification and TabPad opens that file.

My reminder didn't go off.

	•	Check Settings → Notifications → TabPad and make sure notifications are allowed.
	•	For location reminders, check Settings → Privacy & Security → Location Services → TabPad and make sure location access is allowed.
	•	Low Power Mode and Focus modes can delay or hide notifications.

Why does TabPad want my location?
Only for location-based reminders, and only if you set one up. If you never use location reminders, TabPad never asks.

🛠 Troubleshooting

	1.	Update TabPad to the latest version from the App Store.
	2.	Update iOS / iPadOS under Settings → General → Software Update.
	3.	Force quit and reopen TabPad.
	4.	Restart your device.
	5.	Can't find a file? Look in Files → On My iPhone/iPad › TabPad, or wherever you moved it.

⚠️ Before deleting and reinstalling TabPad, move any files you want to keep out of the TabPad folder, for example to iCloud Drive. Deleting the app also deletes the files stored in its folder.
